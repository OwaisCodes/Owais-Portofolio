# Owais Hasan — React Portfolio

A clean, responsive personal portfolio built with React + Vite.

## Stack

- React
- Vite
- React Router
- Lucide React
- CSS

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Create a GitHub repository, for example `owais-portfolio`.
2. Push this project to GitHub.
3. Go to https://vercel.com and sign in with GitHub.
4. Import the repository.
5. Vercel will detect Vite automatically.
6. Deploy.

The portfolio is already structured with separate routes:

- `/`
- `/about`
- `/services`
- `/projects`
- `/contact`
